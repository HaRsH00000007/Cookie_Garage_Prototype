# Cookie Garage 🍪

Website prototype for **Cookie Garage** — *the home of thick American cookies*.
Orders are taken on Instagram: [@cookiegarageee](https://www.instagram.com/cookiegarageee/).

## Run locally

Plain HTML/CSS/JS — no build step.

```bash
python -m http.server 5500
```

Then open http://localhost:5500

## Structure

```
index.html        page markup
css/style.css     styles + light animations
js/main.js        sticky nav, mobile menu, scroll reveal
assets/images/    logo, product & gifting photos, Instagram QR
assets/video/     hero background video
```
